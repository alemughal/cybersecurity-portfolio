# Cybersecurity Portfolio

Welcome to my cybersecurity portfolio. This repository documents hands-on practical projects, risk assessments, and technical labs completed during my cybersecurity training (including the Google Cybersecurity Professional Certificate).

## 📂 Featured Projects

- **[Security Audit & Risk Assessment (Botium Toys)](./01-security-audit/)**  
  *Frameworks & Tools:* NIST CSF, CIA Triad, Risk Management  
  *Overview:* Conducted an end-to-end internal security audit, identified compliance gaps, evaluated asset vulnerabilities, and delivered remediation controls[cite: 1].

- **[Network Layer Traffic & DNS Incident Analysis](./02-network-traffic-analysis/)**  
  *Protocols & Tools:* `tcpdump`, Layer 3/4 Packet Analysis, DNS, ICMP, UDP  
  *Overview:* Analyzed network packet captures to investigate DNS resolution failures, decoded ICMP unreachable error flags, and formulated server/firewall remediation workflows[cite: 2].

- **[TCP SYN Flood Attack Analysis & Mitigation](./03-tcp-syn-flood-analysis/)**  
  *Protocols & Tools:* Wireshark, TCP 3-Way Handshake, DoS/DDoS Mitigation, HTTPS  
  *Overview:* Analyzed packet captures to detect a TCP SYN flood Denial of Service (DoS) attack, diagnosed connection table exhaustion, and formulated hardening strategies like SYN cookies and firewall rate limiting.

- **[Linux System Hardening & SQL Investigation](./04-linux-sql/)** *(In Progress / Coming Soon)*  
  *Tools:* Linux CLI, Bash, SQL  
  *Overview:* Audited file permissions, managed user access control, and queried database logs to investigate security incidents.

- **[Incident Detection & Response](./05-incident-response/)** *(In Progress / Coming Soon)*  
  *Tools:* SIEM (Splunk/Chronicle), Suricata IDS, Wireshark  
  *Overview:* Monitored network traffic, triaged alerts, and documented incident handling procedures.

- **[Security Automation with Python](./06-python-automation/)** *(In Progress / Coming Soon)*  
  *Tools:* Python, Regular Expressions  
  *Overview:* Developed automation scripts to parse server logs and update firewall IP allow/block lists.
